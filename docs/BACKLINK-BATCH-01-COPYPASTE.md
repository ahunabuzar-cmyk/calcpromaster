# CalcProMaster — Backlink Batch 01 (paste-ready, 5/day × 5 days)

**Ye kya hai:** pehle 25 highest-quality targets, din ke hisaab se baante hue, har ek ke
**ready-to-paste fields** ke saath. Aap sirf login karke paste karo, submit karo, aur
"Proof" column me screenshot/URL note karo. Yehi "2000 backlinks" ki jagah **asli, safe start** hai.

Full 505-target research: `docs/BACKLINK-MASTER-PLAN.md` (aur `.docx`).
Progress tracker: `docs/backlink-tracker.csv`.

---

## Roz ka rule (non-negotiable)

1. **5 submissions/din se zyada nahi.** Blast = Google link-scheme flag.
2. **Har site par UNIQUE password** (password manager). Koi plaintext password kisi doc me na likho.
3. **Description ka ek sentence har site par badlo** — identical text do jagah = weak/replica signal.
4. **Anchor 90% brand** (`CalcProMaster`) ya naked URL. Keyword anchor sirf jab editorially natural lage.
5. **sirf free** listings. Jo "paid-only"/"sponsored" bole — chhod do.
6. Submit ke baad turant tracker me **Status + Proof URL** likho.

## 2000 kyun nahi (aur scaling kahan se aayegi)

2000 mass-submitted links = pattern → Google "link scheme" samajhta hai aur ignore/penalize kar sakta hai.
Scale **link magnets** se aati hai (ek asset, hazaaron organic links):
- Embeddable calculator **widget** (dusre blogs embed karein → attribution link)
- **Data study** ("1,282 calculators / X searches ka analysis") → journalists cite = DR links
- **awesome-list PRs** (har niche me 5–10 repos)
- Open-source **repo + README badge**
