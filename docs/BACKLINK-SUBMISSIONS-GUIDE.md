## 1. StartupBase — startupbase.io — 10 min — SABSE PEHLE
1. **startupbase.io** → **Sign up** (email/Google) → verify
2. Top-right avatar → **Submit Product** (ya startupbase.io/submit)
3. Form: Name `CalcProMaster` · URL `https://calcpromaster.com` · Tagline (block se)
4. Logo: `icon-512.png` · Gallery: og-image.png + 2-3 `/og/*.jpg`
5. Category: **Productivity** ya **Education** · Launch type: **Free launch**
6. Submit → **first comment (maker comment)** likho: kis liye banaya, kaunsa calculator sabse zyada use hota
7. Tracker row + submission ID note karo

## 2. OpenAlternative — openalternative.co — 10 min
1. **openalternative.co/submit** (sign-in Google/GitHub)
2. **"Community" (FREE)** package select karo — paid ki zaroorat nahi
3. Form: same block + **repository field mein github.com/ahunabuzar-cmyk/calcpromaster** (open-source signal)
4. Submit → success page aayega (`/submit/calcpromaster/success`)
5. Note: ye "open-source alternatives" site hai — calculator listing thoda unusual hai, lekin free + real tool hai; agar reject ho to bhi koi loss nahi

## 3. 1000.tools — 1000.tools — 5 min — sabse asaan

2. Same block (short version: name + URL + 1-line desc)
3. Submit — kaafi lightweight listing hai

## 4. DevHunt — devhunt.org — 10 min (submit ab, launch 6 mahine baad)
1. **devhunt.org** → **Sign in with GitHub** (ahunabuzar-cmyk account)
2. **Submit your Dev Tool** → form
3. **Square logo ready rakho** (icon-512.png) + 3 screenshots zaroori
4. Launch date: aaj se ~6 mahine baad ka pick karo (queue honest hai — 2026 guide: avg 6 months free)

## Common rules
- Ek din mein 2-3 se zyada submissions nahi (natural pattern)
- Approval email: inbox + SPAM dono check (SaaSHub wale jaisa)
- Jo listing LIVE ho: tracker mein Status=LIVE + date + anchor note
