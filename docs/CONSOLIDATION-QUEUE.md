## Why this works

1. The twin 308s to the canonical URL (verified live: 1419/1419 sitemap twins).
2. `sitemap.xml` lists only the canonical URL, and every canonical tag self-references it.
3. A recrawl of the canonical URL lets Google drop the twin row and merge the impressions.

Gate: `npm run seo:hosts` fails if a twin ever answers 200 again; `npm run check:canonical-urls`
fails if the built tree or the sitemap re-creates a second form.
