## Method & honest limits

- Matching is token-based on slug + title, with body text as secondary evidence only when the token is uncommon site-wide (a word in every page footer proves nothing).
- `GAP` means no page states the keyword in its title/slug — not that nothing similar exists. A "nearest page" column was tried and removed: a page sharing one incidental title word (an EV burn-rate page for "mortgage expense") reads like an answer and is not one. Check these by hand against the suggested path.
- `WEAK` is a hint to inspect, not a verdict: it means every token is on that page while the title names only part of the keyword.
- `COVERED` deliberately ignores SERP position: the site has pages for the head terms and still sits on page 3-5, so the bottleneck for those is authority/indexing, not another page.
- A `GAP` verdict is about **slug/title wording**, and it is not by itself a licence to build a page: [KEYWORD-TARGET-RESOLUTION.md](KEYWORD-TARGET-RESOLUTION.md) holds the per-row decision (95 of the B/C/D rows are answered by an existing owner page, only 2 have no honest owner). Check that table before creating any URL listed here, and prefer improving the named owner.
- Difficulty columns come from two different vendors (SEO Difficulty vs Competition Index) and are therefore comparable within a file, not across files.
- Re-run after adding pages: `node scripts/audit-keyword-gap.cjs` (the CSVs are committed under `data/keyword-gap/`).
