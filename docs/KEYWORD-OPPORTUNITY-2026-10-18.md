3. **Internal links** — har naye/optimized page ko 3 indexed pages se link karo (`npm run seo:crawl-boost` ke bahar, contextual).
4. **SERP check** — build se pehle 5 minute: top 5 results kaun hain? Agar top 5 mein brand tool + 2 government pages hain, wo keyword chhod do chahe difficulty 10 ho.
5. **Brand/generic/off-core ko chhod do** — 2,000 list ka 402 rows isi category mein hai. Inko "opportunity" samajhna time waste hai.

## 7. Honest limits

- `Search Difficulty` third-party estimate hai, Google ka metric nahi. SERP dekhne ka substitute nahi.
- GSC position 28-day average hai; 686 measured keywords mein se kai ke paas 0 clicks hain — position ka matlab ranking hai, traffic nahi.
- Jo 2,000 rows already covered hain unka GSC position sirf tab pata hai jab wo keyword measured list mein ho; warna "covered but unmeasured" hai.
- §3b ka "koi query nahi" ka matlab **export mein nahi mila** hai. `data/gsc-query-page.json` top 4141 queries ka slice hai, poori query universe nahi — is liye ye "practically zero visibility" hai, "zero impressions" ka mathematical proof nahi.
- Attached file **2,000 rows** hai, 9 lakh nahi. 9 lakh wala export alag hai; ye script usi CSV par `--csv` se chal jayegi (rows 2,000 se zyada ho to bhi). 9 lakh rows par har row ka page-match chalao to runtime bhi badhega aur output ka matlab bhi nahi badlega — pehle head-noun filter lagao.
