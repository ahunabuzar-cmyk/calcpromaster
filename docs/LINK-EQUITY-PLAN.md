## Kaise istemal karein

1. Source page ka content kholo aur ek natural jagah par target ka link daalo (related-tools footer ya prose ke andar — dono crawlable hain).
2. Anchor text wahi rakho jo yahan diya hai: wo target ki apni query se bana hai, is liye reader ko wahi words dikhte hain jo usne search kiye the.
3. Ek hafte mein 10-15 links kaafi hain. Sab ek saath karne se ek hi page par 100 links thoos diye jayenge, jo anchor dilution hai.
4. Change karne ke baad `npm run seo:weekly` chalao — plan khud refresh hoga (link graph build ke baad banta hai).
