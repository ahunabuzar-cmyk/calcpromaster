## Root cause

The domain is roughly two weeks old. Google throttles crawl and indexing for new sites: it
discovers a URL, then decides whether the site as a whole is worth spending index budget on.
This is normal and temporary. The fix is not "more pages" — it is **proving value on the
pages Google already knows**, then letting crawl demand grow. Every lever below is white-hat.

raises the whole site’s crawl appetite.
