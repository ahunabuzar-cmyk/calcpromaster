## 6. Decision rules

- **`stuck`/`thin` page jiski impressions ≥ min** → §5 ka `write`/`expose` action dekho; `expose` pehle karo (sasta), `write` baad mein.
- **`broad`/`hundreds` par bhi impr/query kam** → page sahi queries par hai magar position kam; index-velocity ka `moving` verdict dekho aur position par kaam karo (title/intro/copy), naya content nahi.
- **Growth model ke saath padho** → 200k/300k = indexed pages × per-page reach. Dono barhane ka apna waqt hai.
- **Split `config-mismatch` ho** → sitemap form live 200 form se milao (`node scripts/check-sitemap-coverage.cjs` + `npm run seo:hosts`).
- **Split `consolidation-lag` ho** → kuch mat karo; agle snapshot se compare karo. Ye apne aap girta hai.
