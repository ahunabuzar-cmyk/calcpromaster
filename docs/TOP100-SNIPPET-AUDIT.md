## What each flag means

- **TEMPLATE_META** — the generated shape `"Free X: enter the A and get a B. Every step shown…"`. Google usually rewrites it, so the page loses control of its snippet.
- **RAW_TITLE_TAIL** — the title ends in a raw input label (`Dimension 1, Dimension 2`, `Mm And Mm`, `Total Wall`) instead of the outcome the searcher wants.
- **TITLE_LENGTH** / **META_LENGTH** — outside the build gate (title 30–70, meta 70–185 characters).
- **DUPLICATE** — two pages in this set share the same title.

## Fix path

1. Hand-written title + meta go in `scripts/apply-seo-overrides.cjs` → `LABEL_REPAIRS` (snippet-only entries carry `fix: []`; body-copy repairs keep their `labelFix(...)`).
2. `node scripts/apply-seo-overrides.cjs && node scripts/split-seo.cjs`
3. `npm run deploy:build` — the build gates reject titles outside 30–70 chars.
4. Re-run this audit; the flag should disappear from the built page.

_This audit measures; it never edits copy. Every number in a replacement snippet must come from the tool's own formula._
