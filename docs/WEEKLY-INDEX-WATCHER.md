## 4. API limits — kya script kar sakta hai, kya nahi

| Action | Automatable? | Where |
|---|---|---|
| URL Inspection (read status) | ✅ yes | this script consumes it |
| Sitemap resubmit | ✅ yes | `scripts/gsc-batch-inspect.cjs` / `npm run seo:weekly` |
| IndexNow (Bing, Yandex, Seznam, Naver) | ✅ yes | `npm run indexnow` |
| **Request Indexing (Google)** | ❌ **UI only** | [Search Console](https://search.google.com/search-console) → URL Inspection → Request Indexing |

Google's Indexing API (`indexing.googleapis.com`) accepts **JobPosting** and **BroadcastEvent** URLs only. Using it for calculator pages is unsupported and can trip spam detection, so this repo does not call it. The supported levers are the sitemap, internal links from indexed pages, freshness, and the manual request — in that order.
