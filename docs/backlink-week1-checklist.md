# Week 1 — Backlink Kickoff Checklist (Owner Actions)

**Goal for Week 1: 1–2 live links, maximum.** This is deliberate — a brand-new domain that gains 20 links in a week looks manipulated. Slow and boring wins.

**Site:** https://calcpromaster.com/ · Tracker: `docs/backlink-tracker.csv` · Descriptions: `docs/backlink-outreach-content.md`

---

## Before you submit anything (30 minutes, once)

Have these ready in a folder — every platform will ask for some subset:

- [ ] **Logo:** 512×512 PNG (transparent background) + 180×180 for small thumbnails
- [ ] **Screenshot:** clean capture of a calculator page mid-calculation (a tool showing a real result converts far better than a blank form). 1280×800 or 2400×1500 for retina
- [ ] **Tagline (one line):** "1,201+ free online calculators that run in your browser"
- [ ] **Short description (~300 chars):** use the AlternativeTo description from the outreach pack — do not paste it anywhere else
- [ ] **Category pick:** most directories use "Online Tools", "Web App", or "Utilities" — never "Finance" (this is a general calculator site, not a fintech product)
- [ ] **Email you'll submit from:** a real address on a domain you control; directories using throwaway Gmail addresses get screened

---

## Week 1 submissions (do these two, in this order)

### 1. AlternativeTo — safest, fastest approval
- [ ] Create account, then "Add application" → list CalcProMaster as an **alternative to WolframAlpha and Calculator.net** (both suggestions matter — that's how people find you)
- [ ] Paste the AlternativeTo description from the outreach pack (it's written to their ~300-char limit)
- [ ] Category: Online Tools. Upload logo + screenshot
- [ ] Log in tracker: status → Submitted, date, anchor text used

### 2. Fazier — instant approval, low DR but dofollow
- [ ] Submit with the Fazier description from the outreach pack (different text — never reuse)
- [ ] Screenshot + one-line tagline
- [ ] Log in tracker

**Do NOT submit to Product Hunt this week.** PH is a launch-day event (Tue/Wed, 00:01 PT, maker comment ready, gallery assets prepared). Treat it as a Week 4+ project on its own — a rushed PH launch with no comments is worse than no launch.

---

## While you wait (zero-risk, not counted toward link velocity)

- [ ] Set up a **GitHub issue template** on your repo so Awesome-list PRs later have a one-line description + URL format ready
- [ ] Draft your **Indie Hackers build-log post** (don't post yet — that's Week 3): "How I built 1,201 calculators with zero funding" angle from the outreach pack
- [ ] Verify the **embed landing page** loads and the four widgets work: https://calcpromaster.com/embed/ — this is your best natural-link asset; every blogger who embeds creates a link you never asked for

---

## Logging rule (non-negotiable)

The same day you submit, fill the tracker row: Status → `Submitted`, date, anchor text used, notes. When it goes live: status → `Live`. If rejected: `Rejected` + one-line reason. A tracker with gaps is useless 6 months later when you need to audit your anchor-text distribution.
