# CalcProMaster Tools — Quick Reference

Short, exact reference pages for everyday calculations, published as plain HTML on GitHub Pages.
Each page is self-contained (no build step, no tracking scripts, no dependencies) so it loads instantly and works offline once cached.

## Pages

| Page | What it covers |
|---|---|
| `index.html` | Landing page with links to the reference sheets and calculators |
| `unit-conversion-chart.html` | Exact unit conversion factors for length, weight, volume, area, speed, pressure and temperature |
| `percentage-reference.html` | Every percentage formula on one page: percent-of, percent change, reverse percentages, percentage points |
| `emi-table.html` | Loan EMI reference (monthly instalment factors) |

## Why these pages exist

Search results for "unit conversion chart" and "percentage formula" are full of rounded, ad-heavy tables.
These pages use the exact defined factors (2.54 cm per inch, 0.45359237 kg per pound) and show the worked arithmetic,
so the numbers here match a calculator result rather than a memorized approximation.

## Publishing

This repo is served from the `main` branch root via GitHub Pages.
To add a page, drop an `.html` file in the root and link it from `index.html`. No configuration needed.
