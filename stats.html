What these numbers do not measure

Impressions count a result appearing on screen, not a person reading it. A page that ranks on page four can collect impressions for months without a single click, and a page that ranks first for a question already answered in the snippet can get plenty of impressions and few visits. Search Console also omits anonymised queries, so the long tail is undercounted. Nothing here measures whether a visitor found the answer useful: a session that ends in eight seconds after the number was read is a success for a calculator, and there is no metric on this page that would know the difference.

How often this page updates

The page is regenerated by the weekly refresh workflow, not edited by hand. Search Console data lags by roughly two to three days, coverage reports lag further, and URL Inspection is a snapshot of one moment for one URL. Each table states the window it covers; comparing two windows of different lengths is the fastest way to misread a young site, which is why the run-rate rows sit beside the 28-day average instead of replacing it.

How to read this

Two things move a new site: how many pages Google has indexed, and how high each indexed page ranks. Impressions respond to both, and clicks follow impressions at the position the page holds — so a growing impression line with a low click count simply means the pages are still on pages 2-5. The about page describes how the calculators themselves are verified.

Figures come from Google Search Console (performance and coverage exports) and from a weekly automated refresh. The repository keeps the raw exports, so any number on this page can be traced back to the file it came from. Copy changes are dated in the changelog, so a movement in these numbers can be tied back to a specific edit.
